# «НЕ ОТПРАВЛЯЙТЕ»

Интерактивная CRM-игра для стенда «Орион Технологии» в ритейле: одежда, продукты и бытовая техника. Полностью локальная: внешние библиотеки и интернет не требуются.

## Запуск

```bash
python3 serve.py
```

Открыть `http://127.0.0.1:4173`. На macOS можно дважды нажать `start-mac.command`, на Windows — `start-windows.bat`.

## Управление

- мышь или touch;
- `A` / `←` — не отправлять;
- `D` / `→` — отправить;
- `Enter` / `Space` — начать игру.

Таймер: 22 → 18 → 18 → 15 → 15 → 12 секунд.

Физические кнопки стенда: USB HID на клавиши `A` и `D`.
